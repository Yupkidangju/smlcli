# TUI 디자인 참조 자료

이 디렉터리의 HTML/PNG/DESIGN 자료는 `smlcli` TUI 의사결정에 사용한 reference corpus다.

- runtime에서 로드하거나 실행하지 않는다.
- Cargo source package와 release artifact에 포함하지 않는다.
- 제품 계약은 `designs.md`와 실제 `src/tui/` 구현이 소유한다.
- reference와 구현이 충돌하면 reference를 현재 동작 근거로 사용하지 않는다.
- 새 자료를 추가할 때 출처, 생성 시점, 대응 화면을 이 문서에 기록한다.
